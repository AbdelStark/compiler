# External Semantic Parity Audit

This document defines the parity-audit bridge between the in-process runtime and external interpreters (`arkd` / `introspector`).

## Goal

Run identical script vectors through:
- Arkade in-process runtime (this repository)
- External interpreter adapter command

Then compare outcome class (`script_true`, `script_false`, `runtime_error`) for each vector.

## Vector Source

Parity vectors are stored in:
- `tests/parity_vectors/*.json`

Validation tests:
- `tests/runtime_parity_vectors_test.rs`
- `tests/runtime_external_parity_audit_test.rs`

## External Adapter Contract

Set environment variable:
- `ARKADE_PARITY_EXTERNAL_CMD`

The command must accept one argument:
- path to input JSON file generated by test harness

The command must print JSON to `stdout` with schema:

```json
{
  "kind": "script_true"
}
```

or

```json
{
  "kind": "script_false"
}
```

or

```json
{
  "kind": "runtime_error",
  "error_code": "OptionalExternalCode"
}
```

Input JSON schema passed to adapter:

```json
{
  "name": "vector_name",
  "asm": ["OP_1", "OP_VERIFY"],
  "strict_placeholders": false,
  "bindings": {
    "x": { "type": "int", "value": 1 },
    "y": { "type": "bytes_hex", "value": "deadbeef" },
    "z": { "type": "symbol", "value": "foo" },
    "ok": { "type": "bool", "value": true }
  }
}
```

## Commands

Run local parity vectors only:

```bash
cargo test --test runtime_parity_vectors_test
```

Run bridge parity against external adapter:

```bash
ARKADE_PARITY_EXTERNAL_CMD="/path/to/adapter" cargo test --test runtime_external_parity_audit_test -- --nocapture
```

Run both:

```bash
cargo test --test runtime_parity_vectors_test --test runtime_external_parity_audit_test
```

## Notes

- `runtime_external_parity_audit_test` no-ops (passes without execution) when `ARKADE_PARITY_EXTERNAL_CMD` is not set.
- Binding materialization for vectors supports deterministic real signatures and keypairs through label-based generation.
